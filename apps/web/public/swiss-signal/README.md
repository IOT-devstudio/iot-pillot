# 瑞士信号 · 登录 / 注册 / 普通用户界面

延续之前 `student-recruitment-styles.prototype.html` A「瑞士信号」的视觉语言：电蓝 `#1739f5`、荧光黄 `#e9ff6c`、暖纸色 `#f3f4ed`、大字、强网格、直角色块、横向方向章节与信号星。

## 预览

- 直接打开相邻的 `../swiss-signal.html`；CSS 和 JS 都是相对路径，无外部资源或新增依赖。
- 也可从仓库根运行 `pnpm --filter @iot-pillot/web dev`，访问 `http://localhost:5173/swiss-signal.html`。
- 页面顶部可切换登录、注册和用户首页；对应 `#login`、`#register`、`#home`。
- Vite 构建会把文件原样复制到 `dist/swiss-signal.html` 和 `dist/swiss-signal/`。

## 体验

- 登录：任意有效格式的演示邮箱、至少 8 位密码；支持密码显隐、免填写进入首页。
- 注册：称呼、邮箱、密码、确认密码与演示说明勾选；拦截空白称呼、短密码和不一致密码。
- 用户首页：前端 / 后端 / Agent 三个方向；左右按钮、触摸滚动或聚焦轨道后使用方向键切换章节。
- 方向详情：记录本次页面体验的报名意向，同方向不会重复计数。
- 我的申请：展示固定的示例审核进度，可打开详情。
- 个人资料：称呼、兴趣方向和简介只在本次页面体验内保存，称呼同步到首页；刷新后重置。
- 2D 动效：信号星旋转、信号带循环、表单横向滑动、按钮扫色、滚动显影。页脚可暂停 / 恢复；系统减少动态效果设置会关闭动画。
- 弹窗支持 Escape、关闭按钮、点击外部关闭，关闭后焦点回到原入口；未显示的表单使用 `inert` 防止误聚焦。

此处没有真实登录、注册、资料保存、招新、邮件或数据库请求。密码不保存到页面状态、浏览器存储、日志或网络，并在演示登录 / 注册提交后清空表单。资料与意向仅在页面内存中保留。未修改现有 Vue 页面、路由或 API。

## 动效增强

`motion.js` 使用浏览器原生 Web Animations API 与 CSS 编排动效，无新增依赖：

- 标题逐行从遮罩中揭示；表单标题、字段与操作按钮错落入场。
- 登录 / 注册继续横向滑动；账号入口与首页之间用三列蓝黄遮罩连贯转场，快速切换保留最后一次选择。
- 导航选中背景平滑移动；按钮提供轻微磁吸与点击回弹；输入框聚焦时展开底部线条。
- 信号星加入跟随缓动、呼吸中心与扩散圆环，背景网格缓慢漂移并叠加扫描光带。
- 首页数字递增、滚动星形视差、方向章节编号与符号横向视差、申请阶段顺序出现与扫描线。
- 弹窗打开 / 关闭均有过渡，内容分批入场；Escape、点击外部和保存操作沿用同一个关闭流程。
- 手机 / 触摸设备关闭磁吸；后台页面停止指针和滚动更新；视差通过事件触发的 requestAnimationFrame 合并更新。
- 暂停或开启系统减少动态效果时，让正在执行的原生动画完成到最终状态，避免遮罩或透明内容停留在中间。
- 页面进入后台时结束未完成的过渡；动画设有按自身时长计算的完成期限，浏览器暂缓渲染时也不会持续占住转场。

增强后的实际检查：快速连点最终选择正确；转场中暂停后遮罩正常退场；系统减少动态效果时运行中的页面动画为 0；报名意向计数、资料修改、弹窗关闭正常。登录 / 注册 / 首页在 390、650、768、1440 像素宽度无横向溢出，320 像素也补查通过。JavaScript 语法、Git 格式、275 项前端测试与生产构建通过，构建目录的 `motion.js` 与源文件哈希一致。
