# 管理端全屏侧栏与控制台样式升级设计

## 目标与依据

以用户确认的 B 版全屏原型 `.superpowers/brainstorm/admin-redesign-01/content/dashboard-fullscreen-b-v3.html` 为视觉依据，解决两件事：顶部导航与控制台快捷入口重复；主内容被 1200px 容器限制，宽屏下留白过多。保留现有暖纸、藏青、细网格的品牌语言，不改变业务接口或权限规则。

## 范围

- 管理侧页面共用左侧导航：控制台、意向成员列表与详情、用户与权限，以及表单管理、邮件模板、系统设置占位页。
- 控制台移除重复的快捷入口卡片，改成注册用户主指标、右侧管理员和发信总数两个次指标、下方系统状态横条；最近用户与最近发信并列展示。
- 桌面侧栏可在完整态与图标态之间切换；状态由共享布局中的 Vue `ref` 管理，切换管理页时保留，不引入 Pinia。窄屏改为可开关的抽屉导航，并提供可见的关闭方式。
- 其他管理页沿用现有业务内容，只统一外壳、内容宽度、页面间距和响应式表现。登录页与普通用户页面不变。

## 结构与状态

在 `App.vue` 根据显式路由元信息 `adminShell: true` 包裹 `AdminLayout`；不改各页面的 URL 或 `allowRoles`，避免路由重组影响权限守卫。`AdminLayout` 负责侧栏、移动端导航入口、主内容区域与折叠状态，子页面通过默认插槽呈现。所有管理页移除各自的 `AppHeader`，保留 `PageHeader` 和现有业务组件。管理侧路由都显式标注 `adminShell: true`；普通用户和登录路由不标注。

侧栏导航仍使用现有真实目标路径，详情页点亮“意向成员”；控制台只精确匹配 `/dashboard`，防止与 `/dashboard/admins` 同时高亮。占位页仍可进入，但不新增假功能。折叠按钮具有 `aria-label`、`aria-expanded` 与键盘焦点态；图标态链接仍有可访问名称。移动端抽屉打开时有遮罩，选中链接或按 Escape 后关闭。

## 视觉与数据表现

全屏采用 `min-height: 100dvh`，左侧固定宽度侧栏、右侧自适应内容区；内容内部设置约 1670px 的上限，避免超宽屏阅读距离过长。背景在现有网格上增加非常淡的局部光晕和几何层次，面板保持暖白、细边线与克制阴影，不使用重渐变。标题、指标数字和表格信息形成三级视觉层次；窄屏先纵向排列指标与列表，再缩小间距，不允许横向溢出。

控制台继续使用已有四个并行请求：`fetchReady`、`listAdminUsers`、`listAdmins`、`listMails`。各卡片原有 loading、error、retry 独立性不变；“发信总数”仍表示累计值，不误称近期数。系统状态按真实 `/health/ready` 结果显示就绪、依赖不可用或错误，不把原型中的“正常运行”写死。最近发信无记录时保留清晰空态；用户列表继续链接完整用户页。退出登录沿用现有 `SignOutButton`。

## 不做的事

不新增 Pinia、不修改 API、不重做权限系统、不实现占位模块、不引入新的图标或动画依赖、不触碰 3D 登录与用户侧页面。原型中的 `#` 假链接、演示数据和固定日期不会进入正式页面。

## 验收

1. 桌面管理页只有左侧主导航；控制台不再出现重复快捷入口。
2. 控制台主指标、两个次指标及状态条对应真实数据，并保留逐源加载、失败与重试。
3. 所有管理页侧栏导航、高亮和折叠行为一致；移动端能够打开、关闭并使用导航。
4. 关键宽度下无横向滚动，键盘可操作且焦点可见，尊重 `prefers-reduced-motion`。
5. 路由角色限制与原有管理动作不回退；前端测试、类型检查和构建通过。
