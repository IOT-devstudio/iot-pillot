# 个人资料中文姓名（#154）

个人资料 `PUT /api/v1/me` 中提交 `name` 时，必须为 2–20 个 Unicode 汉字，包含扩展区汉字；拒绝 null、空串、英文、数字、空格、标点和表情。错误提示统一为「姓名须为 2–20 个中文汉字」。注册规则独立，本次不调整。

未传 `name` 时保留原姓名，不追溯校验历史数据。个人设置只在姓名发生变化时发送该字段，因此历史英文姓名用户仍可修改其他资料；主动更名必须满足新规则。

手动保存、路由离开自动保存及刷新 keepalive 保存使用同一校验。非法姓名不发送保存请求，保留用户输入并设置字段错误。发布需要同步部署前后端。
